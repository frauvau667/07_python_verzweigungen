Listen in Python

Viele Werte unter einem Namen speichern: Listen anlegen, über den Index zugreifen und mit Methoden wie append(), remove() oder sort() verarbeiten.

i Warum Listen?

Bisher wurde jeder Wert in einer eigenen Variablen gespeichert. Das wird schnell unübersichtlich: Sollen etwa die Windstärken eines Sturmtiefs ausgewertet werden, bräuchte man für jeden Messwert eine Variable – bei mehreren hundert oder tausend Messwerten ist das nicht mehr zu verwalten.

Ohne Liste
messwert1 = 100.2
messwert2 = 80.5
messwert3 = 49.4
messwert4 = 55.4
# … für jeden Wert eine Variable
Mit Liste
messwerte = [100.2, 80.5, 49.4, 55.4]

Ein Name für alle Werte. Die Liste kann beliebig wachsen, und man kann sie mit einer Schleife durchlaufen.

1 Aufbau einer Liste

Eine (eindimensionale) Liste speichert mehrere Werte hintereinander unter einem Namen. Sie wird mit eckigen Klammern [ ] angelegt, die Elemente werden durch Kommas getrennt. Die Werte müssen nicht denselben Datentyp haben.

liste1 = [1, 3, 5, -10]
tage = ["Montag", "Dienstag", "Mittwoch"]
monat1 = ["Januar", 1, 31, 8.4]

Jedes Element hat eine Position, den Index. Gezählt wird ab 0. Das letzte Element hat deshalb den Index Anzahl der Elemente − 1. Zusätzlich kann man von hinten zählen: -1 ist das letzte, -2 das vorletzte Element usw.

Tippe auf ein Element von monat1

Oben steht der Index von vorne, unten (orange) der Index von hinten.

Der Index gibt an, wie weit ein Element vom Anfang der Liste entfernt ist. Das erste Element ist 0 Schritte vom Anfang entfernt, das zweite einen Schritt usw. So kann der Computer die Speicheradresse eines Elements direkt berechnen: Startadresse + Index × Größe eines Elements.

Diese Zählweise stammt aus frühen Programmiersprachen wie C und wurde von fast allen späteren übernommen.

„Es gibt nur zwei schwierige Probleme in der Informatik: Cache-Invalidierung, die Benennung von Dingen und Off-by-one-Fehler.“

Ein Off-by-one-Fehler ist ein Fehler um genau eins – etwa liste[len(liste)] statt liste[len(liste) - 1]. Der Witz macht ihn gleich selbst: Er kündigt zwei Probleme an und zählt drei auf.

Lesen und Ändern über den Index

Über liste[index] liest man ein Element. Mit liste[index] = wert bekommt es einen neuen Wert. Ein Index außerhalb der Liste führt zu einem IndexError.

monat2 = ["Februar", 2, 28]
print(monat2[0])     # Februar
print(monat2[-1])    # 28  (letztes Element)
monat2[2] = 29       # Schaltjahr: Wert ändern

Index-Tester: monat2 = ["Februar", 2, 28]

Python passt auf: Ein Index außerhalb der Liste führt sofort zu einem IndexError. Programmiersprachen wie C prüfen das nicht – dort liest das Programm einfach weiter im Speicher, egal, was dort steht.

Genau das war 2014 die Sicherheitslücke „Heartbleed“ in OpenSSL, einer Software, die einen großen Teil der verschlüsselten Internetverbindungen absichert. Ein Server schickte auf eine Anfrage hin so viele Daten zurück, wie der Absender behauptete geschickt zu haben – ohne die Länge zu prüfen. So konnten Angreifer bis zu 64 KB aus dem Arbeitsspeicher des Servers auslesen, darunter Passwörter und geheime Schlüssel. Millionen Server mussten aktualisiert und Zertifikate ausgetauscht werden.

3 Mit Listenelementen rechnen

Mit einem einzelnen Listenelement kann man genauso arbeiten wie mit einer Variablen – rechnen, vergleichen, ausgeben.

monat2 = ["Februar", 2, 28]
arbeitstage_feb = monat2[2] - 4 * 2    # 28 - 8 = 20
print(arbeitstage_feb)                 # 20

Listen-Labor: Probiere die Methoden aus

Texte bitte in Anführungszeichen eingeben, z. B. "April", Kommazahlen mit Punkt.

Achtung bei sort(): sort() verändert die Liste selbst und gibt None zurück. liste = liste.sort() macht die Liste deshalb kaputt – richtig ist einfach liste.sort(). Wer die ursprüngliche Liste behalten will, nimmt sortiert = sorted(liste). Listen mit gemischten Datentypen (Text und Zahl) lassen sich nicht sortieren.
Achtung beim Kopieren: kopie = liste erzeugt keine Kopie, sondern einen zweiten Namen für dieselbe Liste. Änderungen an kopie verändern auch liste. Eine echte Kopie liefert kopie = liste.copy().

3.2 Listen durchsuchen mit in

Oft will man nur wissen, ob ein Wert in einer Liste vorkommt – etwa, ob ein Name auf der Gästeliste steht. Dafür braucht man keine Schleife: Der Operator in durchsucht die Liste und liefert True oder False. Mit not in prüft man, ob ein Wert fehlt.

Mit Schleife (umständlich)
gefunden = False
for gast in gaeste:
    if gast == "Ben":
        gefunden = True
print(gefunden)
Mit in (eine Zeile)
print("Ben" in gaeste)

Meist steht in direkt in einer Bedingung:

gaeste = ["Anna", "Ben", "Cem", "Dana"]
name = input("Ihr Name: ")
if name in gaeste:
    print("Willkommen!")
else:
    print("Sie stehen leider nicht auf der Liste.")

Probier's aus: gaeste = ["Anna", "Ben", "Cem", "Dana"]

Tipp: in vergleicht exakt – auch Groß- und Kleinschreibung zählt: "ben" in gaeste ist False. Und wer die Position eines Werts braucht, prüft zuerst mit in und ruft erst dann index() auf – so gibt es keinen ValueError.

3.3 Listen mit einer Schleife durchlaufen

Mit for wert in liste: nimmt die Schleife nacheinander jedes Element. Braucht man zusätzlich den Index, läuft man mit for i in range(len(liste)): über alle Indizes und greift mit liste[i] zu.

Beispiel: Die Windstärken eines Sturmtiefs werden ausgewertet. Gehe das Programm mit „Schritt“ durch und beobachte summe und wert im Arbeitsspeicher.

! Typische Fehler

Index zu groß

tage = ["Mo", "Di", "Mi"]
print(tage[3])
print(tage[2])    # oder tage[-1]

Bei 3 Elementen ist der letzte Index 2: IndexError: list index out of range.

In leere Liste schreiben

werte = []
werte[0] = 5
werte = []
werte.append(5)

Eine leere Liste hat noch keinen Platz mit Index 0.

Ergebnis von sort() speichern

zahlen = zahlen.sort()
zahlen.sort()

sort() gibt None zurück – danach wäre zahlen leer (None).

Wert nicht vorhanden

tage.remove("So")
if "So" in tage:
    tage.remove("So")

remove() und index() melden einen ValueError, wenn der Wert fehlt.
