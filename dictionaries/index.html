1 Was sind Dictionaries?

In Listen greift man über einen Index auf die Elemente zu. Das hat einen Nachteil: Man muss genau wissen, an welcher Stelle ein Wert steht. Werden Elemente eingefügt oder gelöscht, verschieben sich die Indizes der folgenden Elemente – man muss ständig mitzählen.

Dictionaries (deutsch: Wörterbücher) lösen dieses Problem. Auch sie speichern mehrere Werte, aber jeder Wert bekommt einen eindeutigen Schlüssel (englisch key). Zugegriffen wird über diesen Schlüssel – im Schlüssel-Wert-Format (key-value).

Beispiel Telefonbuch: Niemand sucht im Telefonbuch „den dritten Eintrag“. Man sucht die Nummer, die zu einem Namen gehört. Der Name ist der Schlüssel, die Telefonnummer der Wert.

Beispiel: Gesucht ist die Telefonnummer von Alan Turing. In einer Liste muss man wissen, an welcher Stelle sie steht. Wird vorne etwas eingefügt, liefert derselbe Index plötzlich einen falschen Wert. Im Dictionary genügt der Name – egal, was dazukommt.

2 Anlegen und Zugriff

Ein Dictionary wird mit geschweiften Klammern { } angelegt. Darin stehen Schlüssel-Wert-Paare in der Form schlüssel: wert, getrennt durch Kommas.

telefonbuch = {
    "Ada Lovelace": "0681 1815",
    "Alan Turing": "06831 1912",
    "Grace Hopper": "0176 1906"
}

Auf einen Wert greift man zu, indem man den Schlüssel in eckige Klammern hinter den Namen des Dictionarys schreibt. Ein Zugriff über einen Index wie telefonbuch[2] ist nicht möglich – Python sucht dann nach dem Schlüssel 2 und meldet einen KeyError, weil es ihn nicht gibt.

Dasselbe passiert, wenn es den Schlüssel nicht gibt: telefonbuch["Hedy Lamarr"] führt zu KeyError: 'Hedy Lamarr' – das Programm bricht ab.

Sicherer Zugriff mit get(): get() löst keinen Fehler aus, wenn der Schlüssel fehlt – das Programm läuft weiter. Aufbau: telefonbuch.get(schlüssel, standardwert)
  • schlüssel (Pflicht): der gesuchte Schlüssel. Ist er vorhanden, liefert get() den zugehörigen Wert.
  • standardwert (optional): wird zurückgegeben, wenn der Schlüssel fehlt. Lässt man ihn weg, ist das Ergebnis None.

Die Namen in den Beispielen gehören Menschen, die die Informatik geprägt haben:

  • Ada Lovelace (1815) schrieb das erste Computerprogramm der Welt – für eine Rechenmaschine, die nie gebaut wurde.
  • Alan Turing (1912) legte die theoretischen Grundlagen der Informatik und half im Zweiten Weltkrieg, die Verschlüsselungsmaschine Enigma zu knacken.
  • Grace Hopper (1906) entwickelte einen der ersten Compiler. Sie machte auch den Begriff „Bug“ bekannt: 1947 fand ihr Team eine Motte in einem Rechner und klebte sie ins Logbuch – „first actual case of bug being found“.
  • Konrad Zuse (1910) baute 1941 in Berlin mit der Z3 den ersten funktionsfähigen programmierbaren Computer.
  • Margaret Hamilton (1936) leitete die Entwicklung der Software für die Apollo-Mondlandung und prägte maßgeblich den Begriff „Software Engineering“.
  • Hedy Lamarr (1914) war Hollywood-Schauspielerin und Erfinderin: Ihr Frequenzsprungverfahren gilt als Vorläufer heutiger Funktechniken wie WLAN und Bluetooth.
  • Guido van Rossum (1956) erfand Python. Benannt hat er die Sprache nach der Comedy-Gruppe Monty Python – nicht nach der Schlange.

Die Personalnummern in den Beispielen sind übrigens ihre Geburtsjahre.

4 Datentypen in Dictionaries

Die Werte dürfen jeden Datentyp haben – auch Listen oder andere Dictionaries. Innerhalb eines Dictionarys dürfen die Datentypen gemischt werden.

mitarbeiter = {
    "name": "Zuse",
    "personalnummer": 1910,
    "gehalt": 3850.50,
    "teilzeit": False,
    "projekte": ["Z1", "Z3", "Plankalkül"]
}
print(mitarbeiter["projekte"][1])     # Z3

Die Schlüssel dagegen müssen unveränderlich sein. Erlaubt sind z. B. ganze Zahlen (int), Kommazahlen (float), Texte (str) und Wahrheitswerte (bool). In der Praxis verwendet man fast immer Texte oder ganze Zahlen. Listen sind nicht erlaubt, weil man sie verändern kann:

d = {[1, 2]: "a"}     # TypeError: unhashable type: 'list'

Jeder Schlüssel kommt in einem Dictionary nur einmal vor. Wird ein Schlüssel ein zweites Mal verwendet, überschreibt er den ersten Eintrag.

5 Dictionaries durchlaufen

Eine for-Schleife über ein Dictionary liefert nacheinander die Schlüssel. Den Wert holt man über den Schlüssel. Noch übersichtlicher ist items(), das Schlüssel und Wert gleichzeitig liefert:

telefonbuch = {"Ada Lovelace": "0681 1815", "Alan Turing": "06831 1912", "Grace Hopper": "0176 1906"}
Über die Schlüssel
for name in telefonbuch:
    print(f"{name}: {telefonbuch[name]}")
Mit items()
for name, nummer in telefonbuch.items():
    print(f"{name}: {nummer}")

Beide Schleifen geben dasselbe aus:

Ada Lovelace: 0681 1815
Alan Turing: 06831 1912
Grace Hopper: 0176 1906

keys(), values() und items() liefern eigene Datentypen (dict_keys, dict_values, dict_items). Braucht man eine echte Liste, wandelt man sie mit list() um:

print(telefonbuch.keys())           # dict_keys(['Ada Lovelace', 'Alan Turing', 'Grace Hopper'])
print(list(telefonbuch.keys()))     # ['Ada Lovelace', 'Alan Turing', 'Grace Hopper']
print(list(telefonbuch.items()))    # [('Ada Lovelace', '0681 1815'), ('Alan Turing', '06831 1912'), ('Grace Hopper', '0176 1906')]

list(telefonbuch.items()) ergibt eine Liste von Paaren – jedes Paar steht in runden Klammern.

Beispiel: Ein Dictionary eignet sich hervorragend zum Zählen. Gehe das Programm mit „Schritt“ durch und beobachte, wie zaehler wächst.

6 Typische Anwendungen

Ein Datensatz: Merkmale eines Objekts

Ein Dictionary kann die Daten einer Person (oder eines Produkts, eines Fahrzeugs …) beschreiben. Jeder Schlüssel ist ein Merkmal. Man muss sich keine Indizes merken, und Merkmale können jederzeit hinzukommen.

mitarbeiterin = {"name": "Hopper", "vorname": "Grace", "email": "grace.hopper@example.de", "abteilung": "Compilerbau"}
print(mitarbeiterin["email"])
mitarbeiterin["telefon"] = "0176 1906"     # neues Merkmal

Eindeutige Kennung als Schlüssel

Haben Daten eine eindeutige Nummer (Kundennummer, Personalnummer, Matrikelnummer), eignet sie sich als Schlüssel:

personal = {
    1815: "Ada Lovelace",
    1906: "Grace Hopper",
    1910: "Konrad Zuse",
    1912: "Alan Turing"
}
print(personal[1912])     # Alan Turing

Beides kombiniert

Die Werte können selbst Dictionaries sein: Jede Personalnummer (Kennung) verweist auf einen Datensatz. So entsteht eine kleine Datenbank – mit zwei Schlüsseln nacheinander greift man auf ein Merkmal zu:

personal = {
    1906: {
        "name": "Hopper",
        "vorname": "Grace",
        "email": "grace.hopper@example.de"
    },
    1910: {
        "name": "Zuse",
        "vorname": "Konrad",
        "email": "konrad.zuse@example.de"
    }
}
print(personal[1906]["email"])     # grace.hopper@example.de

personal[1906] liefert den Datensatz von Grace Hopper (ein Dictionary), ["email"] daraus die E-Mail-Adresse.

! Typische Fehler

Alle Beispiele beziehen sich auf dieses Dictionary:

telefonbuch = {"Ada Lovelace": "0681 1815", "Alan Turing": "06831 1912", "Grace Hopper": "0176 1906"}

Zugriff über einen Index

print(telefonbuch[0])
print(telefonbuch["Ada Lovelace"])

Dictionaries haben keinen Index: KeyError: 0.

Schlüssel existiert nicht

print(telefonbuch["Hedy Lamarr"])
print(telefonbuch.get("Hedy Lamarr", "unbekannt"))

KeyError: 'Hedy Lamarr'. Mit get() und Standardwert gibt es keinen Fehler – oder vorher mit in prüfen.

Groß-/Kleinschreibung im Schlüssel

print(telefonbuch["alan turing"])
print(telefonbuch["Alan Turing"])

Schlüssel müssen exakt übereinstimmen – "alan turing" und "Alan Turing" sind verschiedene Schlüssel: KeyError: 'alan turing'.

Doppelpunkt vergessen

d = {"rot", 1, "blau", 2}
d = {"rot": 1, "blau": 2}

Ohne Doppelpunkte entsteht kein Dictionary, sondern eine Menge (set).
