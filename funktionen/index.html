Funktionen in Python

Code einmal schreiben, beliebig oft verwenden: eigene Funktionen mit def definieren, Werte übergeben, Ergebnisse mit return zurückgeben und verstehen, wo Variablen gelten.

1 Was sind Funktionen – und wozu?

Eine Funktion ist ein benannter Programmteil, der eine bestimmte Aufgabe erledigt und bei Bedarf aufgerufen wird. Viele Funktionen kennst du schon: print(), input(), int(), len(). Wie sie intern programmiert sind, muss man nicht wissen. Für die Verwendung reicht es zu wissen:

  • wie die Funktion heißt (Funktionsname),
  • welche Werte man ihr übergeben muss (Parameter),
  • ob und was sie zurückgibt (Rückgabewert).

Warum eigene Funktionen?

VorteilBedeutung
WiederverwendbarkeitEine Funktionalität wird einmal programmiert und kann beliebig oft aufgerufen werden, ohne den Code zu kopieren.
ÜbersichtlichkeitDas Programm wird in kleine, verständliche Teile (Module) gegliedert, statt als ein langer Block von oben nach unten zu laufen.
WartbarkeitWiederholungen (Redundanz) im Code werden vermieden. Fehler müssen nur an einer Stelle korrigiert werden.

2 Aufbau einer Funktion

Syntax
def funktions_name(parameter1, parameter2):
    Anweisung1
    ...
    return ergebnis      # optional
  • def leitet die Definition ein. Danach folgen der Name, runde Klammern mit den Parametern (oder leere Klammern) und ein Doppelpunkt.
  • Der Funktionskörper ist eingerückt.
  • Die Definition führt noch nichts aus. Erst der Aufruf funktions_name(…) startet die Funktion.
  • Eine Funktion muss definiert sein, bevor sie aufgerufen wird – die Definition steht also weiter oben im Code.
  • Funktionsnamen werden wie Variablennamen klein geschrieben und beschreiben, was die Funktion tut – am besten mit einem Verb: berechne_volumen oder kaffee_kochen.
BegriffBedeutungIm Beispiel def flaeche(laenge, breite): …
ParameterPlatzhalter in der Definition, die beim Aufruf Werte bekommenlaenge, breite
Argumentkonkreter Wert, der beim Aufruf übergeben wirdflaeche(4, 2.5) → 4 und 2.5
RückgabewertErgebnis, das die Funktion mit return an den Aufrufer zurückgibtreturn laenge * breite

3 Die vier Arten von Funktionen

Je nachdem, ob eine Funktion Werte bekommt (Parameter) und ob sie ein Ergebnis zurückgibt (Rückgabewert), unterscheidet man vier Arten. Tippe auf ein Feld:

      Ausgabe oder Rückgabe? Eine Funktion mit print() zeigt ein Ergebnis nur auf dem Bildschirm an – weiterrechnen kann das Programm damit nicht. Mit return bekommt der Aufrufer das Ergebnis und kann es speichern, weiterverarbeiten oder ausgeben. Funktionen mit Rückgabewert sind deshalb meist vielseitiger.
    

  


  
  

    
3.5 Parameter, Reihenfolge und Standardwerte

    
Beim Aufruf werden die Argumente in der Reihenfolge den Parametern zugeordnet. berechne_gesamtkosten(17.5, 3) würde also mit einer Anzahl von 17,5 und einem Preis von 3 rechnen. Sicherer ist es, die Parameter beim Aufruf beim Namen zu nennen – dann ist die Reihenfolge egal:


berechne_gesamtkosten(3, 17.5)                  # anzahl = 3, preis = 17.5
berechne_gesamtkosten(preis=17.5, anzahl=3)     # gleiche Wirkung, gut lesbar


    
Ein Parameter kann einen Standardwert bekommen (rabatt=0). Wird beim Aufruf kein Wert für ihn angegeben, gilt der Standardwert. Parameter mit Standardwert stehen immer hinter den Parametern ohne Standardwert.

    
Beispiel: Dieselbe Funktion wird zweimal aufgerufen – einmal ohne und einmal mit Rabatt. Beobachte, wie die Argumente in den lokalen Bereich übernommen werden und der Rückgabewert in der globalen Variablen landet.

    

  


  
  

    
3.6 return beendet die Funktion

    
Sobald return ausgeführt wird, ist die Funktion sofort beendet. Alles, was danach im Funktionsblock steht, wird nicht mehr ausgeführt (Entwicklungsumgebungen zeigen solchen Code meist grau an).


def pruefe_alter(alter):
    if alter >= 18:
        return "volljährig"     # Funktion endet hier
    return "minderjährig"
    print("Wird nie ausgeführt")


    
Hat eine Funktion kein return, gibt sie automatisch None („nichts“) zurück. Speichert man das Ergebnis einer solchen Funktion, steht in der Variablen None.


def begruesse(name):
    print(f"Hallo {name}")

ergebnis = begruesse("Lea")   # gibt "Hallo Lea" aus
print(ergebnis)               # None


      


Eine Funktion darf sich selbst aufrufen – das nennt man Rekursion. Ein Klassiker ist die Fakultät: 4! = 4 · 3 · 2 · 1 = 24.

      
def fakultaet(n):
    if n <= 1:
        return 1                      # Abbruchbedingung
    return n * fakultaet(n - 1)       # ruft sich selbst auf

print(fakultaet(4))   # 24


      
Wichtig ist die Abbruchbedingung, sonst ruft sich die Funktion endlos selbst auf. Python bricht dann nach etwa 1000 Aufrufen mit einem RecursionError ab.

      
„Um Rekursion zu verstehen, muss man zuerst Rekursion verstehen.“ – Und wer bei Google nach „recursion“ sucht, bekommt die Rückfrage: „Meinten Sie: recursion“.

    

  


  
  

    
4 Sichtbarkeit von Variablen

    
Jede Variable hat einen Geltungsbereich (englisch scope), der festlegt, wo man auf sie zugreifen kann.

    
    
      
  • Global: Eine Variable, die außerhalb jeder Funktion angelegt wird, ist global. Man kann sie im ganzen Programm lesen – auch innerhalb von Funktionen.
    • 
      
  • Lokal: Eine Variable, die innerhalb einer Funktion angelegt wird, ist lokal. Sie existiert nur, solange die Funktion läuft, und ist außerhalb unbekannt. Das gilt auch für die Parameter einer Funktion.
    • 
      
  • Verbergen: Hat eine lokale Variable denselben Namen wie eine globale, verdeckt sie die globale innerhalb der Funktion. Die globale Variable bleibt dabei unverändert.
    • 
    

    
Beispiel: Gehe das Programm mit „Schritt“ durch und vergleiche den globalen und den lokalen Bereich.

    

    
Weil lokale Variablen nur in ihrer Funktion gelten, dürfen verschiedene Funktionen Variablen mit demselben Namen haben, ohne sich gegenseitig zu stören. Der Versuch, eine lokale Variable außerhalb ihrer Funktion zu benutzen, führt dagegen zu einem Fehler:


def play_music():
    song = "Running up that hill"

play_music()
print(song)     # NameError: name 'song' is not defined


    

      Empfehlungen:
      
    
        
  1. Achte bewusst auf globale und lokale Bereiche.
    2. 
        
  2. Vermeide es, in Funktionen globale Variablen zu verwenden.
    3. 
        
  3. Übergib Werte, die eine Funktion braucht, als Parameter, und gib Ergebnisse mit return zurück. So ist jede Funktion in sich abgeschlossen und leicht zu testen.
