1 Was sind Operatoren?

Operatoren sind Symbole, die eine Aktion auslösen – zum Beispiel eine Rechnung oder einen Vergleich. In einem Ausdruck (z. B. 2 + 3 * 4) können mehrere Operatoren vorkommen. In welcher Reihenfolge gerechnet wird, bestimmen die Vorrangregeln der Mathematik („Punkt vor Strich“) und Klammern.

3* / // %„Punktrechnung“
4+ -„Strichrechnung“

Operatoren auf derselben Stufe werden von links nach rechts ausgewertet.

Ganzzahlige Division und Modulo

// und % gehören zusammen: // gibt an, wie oft der Divisor vollständig in den Dividenden passt, % liefert den Rest, der dabei übrig bleibt.

Beispiel: 20 Teilnehmende sollen in Gruppen zu je 6 Personen eingeteilt werden. Es entstehen 20 // 6 = 3 vollständige Gruppen, und 20 % 6 = 2 Personen bleiben übrig. Probe: 3 · 6 + 2 = 20.

Rechen-Labor: alle arithmetischen Operatoren auf einmal

Probiere auch Kommazahlen (mit Punkt), negative Zahlen oder 0 als b.

// und % mit Kommazahlen und negativen Zahlen

Im Rechen-Labor fällt auf: // und % funktionieren auch mit Kommazahlen. Das liegt daran, wie Python die beiden Operatoren definiert:

  • a // b bedeutet: a / b berechnen und auf die nächstkleinere ganze Zahl abrunden. Das geht mit jeder Zahl, nicht nur mit ganzen Zahlen.
  • a % b ist der Rest, der dabei bleibt: a - (a // b) * b.
  • Der Datentyp richtet sich nach den Operanden: Ist mindestens einer davon ein float, ist auch das Ergebnis ein float – selbst wenn es einen ganzzahligen Wert hat.
AusdruckErgebnisErklärung
7.5 // 23.07.5 / 2 = 3.75, abgerundet 3 – als float, weil 7.5 ein float ist
7.5 % 21.57.5 − 3 · 2 = 1.5
-7 // 2-4−7 / 2 = −3.5, abgerundet −4 (nicht −3: abgerundet wird immer zur kleineren Zahl)
-7 % 21−7 − (−4) · 2 = 1
Praxisbeispiel: Eine Schicht dauert 2 Stunden. Wie viele vollständige Schichten passen in 7,5 Stunden? 7.5 // 2 ergibt 3.0 Schichten, und 7.5 % 2 ergibt 1.5 Stunden Restzeit.
Hinweis: Kommazahlen werden im Computer nicht immer exakt gespeichert. Deshalb können bei // und % mit Kommazahlen kleine Abweichungen entstehen, z. B. ergibt 0.3 % 0.1 nicht 0, sondern 0.09999999999999998. In der Praxis verwendet man // und % daher meist mit ganzen Zahlen.

Mit Texten „rechnen“

Auch bei Texten (Strings) gibt es zwei Operatoren: + verbindet Texte, * vervielfacht sie. 'ab' * 2 ergibt 'abab'.

Der unscheinbare Operator % steckt in vielen Anwendungen:

  • Gerade oder ungerade: zahl % 2 == 0
  • Uhrzeiten: 14 Uhr plus 12 Stunden → (14 + 12) % 24 = 2 Uhr
  • Prüfziffern: Bei jeder IBAN muss eine Rechnung mit % 97 den Rest 1 ergeben. So erkennt die Bank Tippfehler, bevor Geld falsch überwiesen wird. Auch ISBN-Nummern von Büchern haben eine Prüfziffer.
  • Caesar-Verschlüsselung: Julius Caesar verschob jeden Buchstaben um 3 Stellen im Alphabet: Aus A wird D. Damit nach Z wieder vorne begonnen wird, rechnet man mit Modulo: (position + 3) % 26. Z hat die Position 25 und wird zu (25 + 3) % 26 = 2, also C.

Auch moderne Verschlüsselung wie RSA, die z. B. beim Onlinebanking und bei HTTPS-Verbindungen eingesetzt wird, rechnet mit Modulo – allerdings mit Zahlen, die mehrere hundert Stellen lang sind. Ihre Sicherheit beruht darauf, dass sich so große Zahlen praktisch nicht in ihre Primfaktoren zerlegen lassen.

! Typische Anfängerfehler

^ statt ** für Potenzen

print(2 ^ 3)    # ergibt 1 !
print(2 ** 3)   # ergibt 8

^ ist in Python keine Potenz, sondern ein ganz anderer Operator. Potenzen schreibt man mit **.

Klammern vergessen

schnitt = 2 + 4 / 2   # 4.0
schnitt = (2 + 4) / 2 # 3.0

Punkt vor Strich gilt auch in Python. Für den Durchschnitt müssen Klammern gesetzt werden.

= statt ==

/ statt //

gruppen = 20 / 6    # 3.3333333333333335
gruppen = 20 // 6   # 3

/ liefert immer eine Kommazahl. Wer nur ganze Gruppen zählen will, braucht //.
