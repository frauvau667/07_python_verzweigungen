1 Was sind Standardbibliotheken?

Python wird mit einer großen Sammlung fertiger Module ausgeliefert – der Standardbibliothek. Ein Modul ist eine Python-Datei mit Funktionen (und Konstanten) zu einem Thema. Statt z. B. eine Wurzelfunktion selbst zu programmieren, nutzt man die fertige Funktion aus dem Modul math.

BereichModule (Auswahl)
Mathematik und Statistikmath, random, statistics
Datum und Zeitdatetime, time
Dateien und Betriebssystemos, shutil, pathlib
Datenformatecsv, json, xml
Netzwerksocket, http
Textbearbeitungre (reguläre Ausdrücke)
Fehlerbehandlung und Protokollelogging, traceback
Standardbibliothek oder externe Bibliothek? Module der Standardbibliothek sind in Python bereits enthalten – eine Installation ist nicht nötig. Daneben gibt es unzählige externe Bibliotheken (z. B. tabulate, numpy, pandas). Diese muss man zuerst im Terminal installieren, z. B. mit py -m pip install tabulate (Windows) bzw. python3 -m pip install tabulate.

2 Module importieren

Bevor man ein Modul nutzen kann, muss man es mit import einbinden. Import-Anweisungen stehen üblicherweise ganz oben in der Programmdatei. Es gibt drei gängige Varianten:

VarianteAufruf danachWann verwenden?
import math
ganzes Modul		math.sqrt(16)Wenn man mehrere Funktionen aus dem Modul braucht. Vorteil: Man sieht sofort, woher eine Funktion stammt. Nachteil: Der Modulname muss vor jeder Funktion stehen.
from math import sqrt, pi
einzelne Funktionen		sqrt(16)Wenn man nur wenige Funktionen braucht. Vorteil: kürzerer Code. Nachteil: Bei vielen Funktionen weiß man nicht mehr, woher sie kommen.
import datetime as dt
mit Alias (Kurzname)		dt.datetime.now()Wenn der Modulname lang ist oder oft vorkommt. Üblich auch bei externen Bibliotheken: import numpy as np.
Besser vermeiden: from math import * importiert alle Namen eines Moduls auf einmal. Dann ist nicht mehr erkennbar, woher eine Funktion stammt, und gleichnamige Funktionen können sich gegenseitig überschreiben.

3.3 Das Modul random

    
random liefert Zufallszahlen und zufällige Auswahlen – für Spiele, Simulationen oder Testdaten.

    

      

        
AufrufBedeutung

        
          
random.randint(a, b)zufällige ganze Zahl von a bis b (beide Grenzen sind möglich)

          
random.uniform(a, b)zufällige Kommazahl zwischen a und b

          
random.random()zufällige Kommazahl zwischen 0 und 1

          
random.choice(liste)zufälliges Element einer Liste

          
random.shuffle(liste)mischt die Liste (verändert sie selbst, gibt None zurück)

        
      

    

    

      
random ausprobieren – jeder Klick liefert ein neues Ergebnis

      

        
        
        
        
        
      

      

      

    

      


Ein Computer arbeitet deterministisch: Gleiche Eingabe führt immer zum gleichen Ergebnis. Echter Zufall ist so nicht möglich. Python verwendet deshalb einen Pseudozufallszahlengenerator (den „Mersenne Twister“): Eine Formel berechnet aus einem Startwert (englisch seed) eine sehr lange Zahlenfolge, die zufällig aussieht.

      
Mit demselben Startwert entsteht immer dieselbe Folge – nach random.seed(42) liefert random.randint(1, 6) bei jedem Programmstart dieselben Würfe. Das ist zum Testen praktisch. Ohne seed() holt sich Python einen Startwert vom Betriebssystem, das dafür z. B. Zeitpunkte von Tastendrücken oder Hardware-Ereignissen sammelt.

      
Für Passwörter und Sicherheitsanwendungen ist random ungeeignet, weil sich die Folge mit genug Aufwand vorhersagen lässt. Dafür gibt es das Modul secrets. Wie gefährlich schlechter Zufall ist, zeigte 2008 ein Fehler in Debian Linux: Nach einer fehlerhaften Code-Änderung gab es für Verschlüsselungsschlüssel nur noch rund 32 000 mögliche Startwerte – alle damit erzeugten Schlüssel ließen sich in kurzer Zeit durchprobieren.

    

  


  
  

    
3.4 Die Module datetime und time

    
datetime arbeitet mit Datum und Uhrzeit: aktuelles Datum abfragen, mit Daten rechnen (z. B. „in 30 Tagen“) und Datumswerte formatiert ausgeben. time eignet sich für Zeitmessungen und Pausen.


import datetime as dt

jetzt = dt.datetime.now()                      # aktuelles Datum und Uhrzeit
in_30_tagen = jetzt + dt.timedelta(days=30)    # mit Daten rechnen
print(jetzt.strftime("%d.%m.%Y %H:%M"))        # deutsches Format, z. B. 21.10.2026 14:05


    

      
datetime ausprobieren

      

        

      

      

      
Formatkürzel: %d Tag, %m Monat, %Y Jahr, %H Stunde, %M Minute, %S Sekunde.

    


import time

start = time.time()      # Sekunden seit dem 1.1.1970 (Zeitstempel)
time.sleep(2)            # Programm 2 Sekunden anhalten
ende = time.time()
print(ende - start)      # ca. 2.0 – so misst man Laufzeiten


    

      
time ausprobieren: Stoppuhr

      

        
        
      

      

    

      


Auf der Hauptplatine jedes Computers läuft eine kleine Echtzeituhr, die von einer Knopfzelle versorgt wird – auch wenn der PC ausgeschaltet ist. Sie geht allerdings ungenau. Deshalb gleicht das Betriebssystem die Uhrzeit regelmäßig über das Internet mit Zeitservern ab (Network Time Protocol, NTP). Diese erhalten ihre Zeit letztlich von Atomuhren – in Deutschland von der Physikalisch-Technischen Bundesanstalt (PTB) in Braunschweig.

      
Intern zählt der Computer die Sekunden seit dem 1. Januar 1970, 0 Uhr (UTC) – genau diese Zahl liefert time.time().

      
Typische Probleme beim Programmieren:

      
    
        
  • Zeitzonen: 9 Uhr in Berlin ist nicht 9 Uhr in New York. Ein Server kann in einer anderen Zeitzone laufen als der Nutzer.
    • 
        
  • Sommerzeit: Am Tag der Zeitumstellung gibt es 2:30 Uhr gar nicht – oder zweimal.
    • 
        
  • Schaltjahre: Der 29. Februar bringt schlecht getestete Programme immer wieder zum Absturz.
    • 
        
  • Datumsformate: 03.04.2026 ist in Deutschland der 3. April, in den USA (04/03/2026) wäre dasselbe Datum anders geschrieben.
    • 
        
  • Jahr-2038-Problem: Ältere Systeme speichern die Sekunden seit 1970 in einer 32-Bit-Zahl. Am 19. Januar 2038 läuft sie über – ähnlich wie beim „Millennium-Bug“ zum Jahr 2000.

4 Tipps für den Einsatz

    

      

        
ModulTypische Anwendungen

        
          
mathBerechnungen in Physik, Technik, Geometrie, Trigonometrie

          
statisticsDatenanalyse: Mittelwerte, Median, Streuung

          
randomSpiele, Simulationen, zufällige Auswahl, Testdaten

          
datetimeKalenderfunktionen, Fristen und Laufzeiten berechnen, Zeitstempel

          
timeLaufzeiten messen, Pausen, Zeitsteuerung

        
      

    

    
    
      
  • Dokumentation nutzen: Alle Module sind unter docs.python.org/3/library beschrieben. Im Programm hilft help(math.sqrt); dir(math) listet alle Namen eines Moduls auf.
    • 
      
  • Gezielt importieren: Nur die Module einbinden, die man wirklich braucht – das hält den Code übersichtlich.
    • 
      
  • Alias sinnvoll einsetzen: Kurznamen wie dt oder np machen langen Code lesbarer.
    • 
      
  • Autovervollständigung verwenden: Nach math. zeigt die Entwicklungsumgebung (z. B. VS Code) alle verfügbaren Funktionen an.
    • 
    

      


Bibliotheken sparen viel Arbeit – man holt sich damit aber auch fremden Code ins Programm, samt seiner Fehler.

      
    
        
  • Log4Shell (2021): In der weit verbreiteten Java-Bibliothek Log4j, die Programme zum Mitschreiben von Ereignissen nutzen, steckte eine Lücke: Eine einzige präparierte Textzeile genügte, um fremden Code auf dem Server auszuführen. Betroffen waren Hunderttausende Systeme – von Cloud-Diensten bis zum Spiel Minecraft.
    • 
        
  • Typosquatting: Angreifer veröffentlichen im Python-Paketverzeichnis PyPI Schadsoftware unter Namen wie reqeusts statt requests. Wer sich bei pip install vertippt, installiert sie selbst.
    • 
      

      
Deshalb: Paketnamen genau prüfen, nur bekannte und gepflegte Bibliotheken verwenden und sie aktuell halten.

    

  


  
  

    
! Typische Fehler

    

      

        
Import vergessen


print(math.sqrt(16))


import math
print(math.sqrt(16))

        
Ohne Import kennt Python das Modul nicht: NameError: name 'math' is not defined.

      

      

        
Modulname fehlt


import math
print(sqrt(16))


from math import sqrt
print(sqrt(16))

        
Nach import math muss math. vor der Funktion stehen.

      

      

        
Eigene Datei heißt wie das Modul


# Datei: random.py
import random


# Datei: wuerfel.py
import random

        
Heißt die eigene Datei random.py, importiert Python sich selbst statt der Bibliothek – es folgen rätselhafte Fehler.

      

      

        
Externe Bibliothek nicht installiert


import tabulate
# ModuleNotFoundError


# im Terminal:
# py -m pip install tabulate

        
Nur die Standardbibliothek ist vorinstalliert. Externe Pakete müssen mit pip installiert werden.
