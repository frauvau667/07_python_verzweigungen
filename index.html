2 Bedingungen

Bei einer Verzweigung hängt der weitere Ablauf von einer Bedingung ab. Eine Bedingung ist eine Frage, die der Computer nur mit True (wahr) oder False (falsch) beantworten kann. Dafür nutzt man Vergleichsoperatoren:

Achtung: = und == sind nicht dasselbe! x = 5 speichert 5 in x. x == 5 fragt, ob x gleich 5 ist.

  • not – dreht das Ergebnis um: aus True wird False und umgekehrt.

2.1 Einseitige Verzweigung

Es wird eine Bedingung geprüft. Ist sie wahr, wird ein Block ausgeführt. Ist sie falsch, passiert nichts – das Programm macht einfach nach der Verzweigung weiter. Im Struktogramm steht dafür im Falsch-Zweig das Zeichen ∅ (leer).

Syntax
if Bedingung:
    Anweisung1
    Anweisung2

Beispiel: Das Programm fragt nach der Temperatur. Nur wenn es wärmer als 25 °C ist, gibt es einen Hinweis aus.

2.2 Zweiseitige Verzweigung

Jetzt gibt es eine Alternative: Ist die Bedingung falsch, wird der else-Block ausgeführt. Es wird also immer genau einer der beiden Zweige ausgeführt – nie beide, nie keiner.

Syntax
if Bedingung:
    Anweisung1
else:
    Anweisung2

Beispiel: Ein Laden hat von 8 bis 18 Uhr geöffnet. Die Bedingung verknüpft zwei Vergleiche mit and – die Uhrzeit muss beide erfüllen.

2.3 Verschachtelte Verzweigung

Manchmal muss man nach einer Entscheidung noch eine weitere Frage stellen. Dann steht eine Verzweigung innerhalb einer anderen. Im Code erkennst du das an der doppelten Einrückung, im Struktogramm an dem kleineren Dreieck im Wahr- oder Falsch-Zweig.

Beispiel: Was soll ich anziehen? Zuerst wird gefragt, ob es regnet – danach je nach Antwort, wie warm es ist.

Wichtig: Es wird immer nur ein Weg durch das Struktogramm genommen. Ist die äußere Bedingung wahr, wird der gesamte Falsch-Zweig (rechte Hälfte) übersprungen – auch die innere Bedingung dort wird gar nicht geprüft.

2.4 Mehrfachauswahl mit elif

elif ist die Abkürzung für „else if“ – „sonst, wenn …“. Eine elif-Bedingung wird nur geprüft, wenn alle Bedingungen davor falsch waren. Anders als else braucht elif immer eine eigene Bedingung.

Syntax
if Bedingung1:
    Anweisung1
elif Bedingung2:
    Anweisung2
else:
    Anweisung3

Beispiel: Die Temperatur wird in Bereiche eingeteilt. Im Struktogramm sieht man gut: Jedes elif ist eine neue Verzweigung im Falsch-Zweig der vorherigen – wie eine Treppe.

Die Reihenfolge zählt! Gib einmal 10 °C ein: 10 ist kleiner als 15 und kleiner als 25. Trotzdem erscheint nur „kühl“, denn nach dem ersten Treffer werden alle weiteren Zweige übersprungen.

2.5 Mehrfachauswahl mit match

Wenn eine Variable mit vielen möglichen Werten verglichen werden soll, ist eine Fallunterscheidung übersichtlicher. In anderen Sprachen heißt das switch-case, in Python (ab Version 3.10) match.

Syntax
match Variable:
    case Wert1:
        Anweisung1
    case Wert2:
        Anweisung2
    case _:
        Anweisung3
  • Die Fälle werden von oben nach unten verglichen. Beim ersten Treffer wird der Block ausgeführt – danach geht es nach der match-Anweisung weiter.
  • case _ ist der „Sonst“-Fall – wie else. Er greift, wenn kein anderer Fall passt.
  • Verglichen werden können z. B. ganze Zahlen, Kommazahlen, Texte und Wahrheitswerte.

Beispiel 1: Eine Fußgänger-Ampel. Teste auch einmal eine Farbe wie „blau“ oder „Rot“ mit großem R!

Mehrere Werte in einem Fall: der Operator |

Mit | (gesprochen „oder“) kann man mehrere Werte zu einem Fall zusammenfassen.

Beispiel 2: Ist heute Wochenende oder Schultag?

Zusatzbedingung mit if im case

Hinter einem case kann zusätzlich eine Bedingung mit if stehen. Der Fall greift dann nur, wenn der Wert passt und die Bedingung wahr ist:

note = 4
hausaufgaben = True

match note:
    case 1 | 2 | 3 | 4 if hausaufgaben == True:
        print("Bestanden")
    case 1 | 2 | 3 | 4 if hausaufgaben == False:
        print("Nicht bestanden – Hausaufgaben fehlen")
    case 5 | 6:
        print("Nicht bestanden")
match oder elif? match eignet sich, wenn du eine Variable mit festen Werten vergleichst (z. B. „rot“, „gelb“, „grün“). Für Bereiche wie „kleiner als 15“ nimmst du if / elif.

! Typische Anfängerfehler

Doppelpunkt vergessen

if alter >= 18
if alter >= 18:

Hinter if, elif, else, match und case steht immer ein Doppelpunkt.

Falsch eingerückt

if alter >= 18:
print("Volljährig")
if alter >= 18:
    print("Volljährig")

Alles, was zum Zweig gehört, wird um 4 Leerzeichen eingerückt. Die Einrückung entscheidet, was zum if gehört!

= statt ==

if farbe = "rot":
if farbe == "rot":

Für einen Vergleich braucht man zwei Gleichheitszeichen.

Text statt Zahl vergleichen

alter = input("Alter? ")
if alter >= 18:
alter = int(input("Alter? "))
if alter >= 18:

input() liefert immer einen Text. Mit int() wird daraus eine Zahl, mit der man rechnen und vergleichen kann.
