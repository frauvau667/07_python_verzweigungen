1 Variablen

Variablen sind – wie in der Mathematik – Platzhalter für Werte, die sich ändern können. Man kann sie sich wie beschriftete Kästchen im Arbeitsspeicher vorstellen: Auf dem Kästchen steht der Name, darin liegt der Wert.

  • Der Wert wird nur vorübergehend gespeichert – solange das Programm läuft. Danach wird der Platz im Arbeitsspeicher wieder freigegeben.
  • Eine Variable bekommt ihren Wert mit dem Zuweisungsoperator =. Links steht der Name, rechts der Wert: x = 3
  • Eine Variable muss zuerst einen Wert bekommen, bevor man sie benutzen kann.
  • In Python muss man den Datentyp nicht angeben. Python erkennt ihn automatisch am zugewiesenen Wert.
  • Bekommt eine Variable einen neuen Wert, wird der alte überschrieben.
Wichtig: = bedeutet in Python nicht „ist gleich“ wie in der Mathematik, sondern „speichere“. alter = alter + 1 heißt: Nimm den alten Wert, rechne plus 1 und speichere das Ergebnis wieder in alter.

Beispiel: Gehe das Programm mit „Schritt“ durch und beobachte, wie im Arbeitsspeicher Kästchen entstehen und sich ändern. Tippe auf eine Codezeile für eine Erklärung.

1.1 Namen für Variablen (Bezeichner)

Bei der Wahl von Variablennamen gibt es Regeln, die Python vorschreibt, und Konventionen (Vereinbarungen), an die sich alle halten sollten, damit Programme gut lesbar sind.

Regeln – sonst gibt es eine Fehlermeldung

  • Python ist case-sensitive: Groß- und Kleinschreibung wird unterschieden. alter und Alter sind zwei verschiedene Variablen!
  • Namen dürfen nicht mit einer Zahl beginnen: 2zahl geht nicht, zahl2 schon.
  • Keine Leerzeichen, keine Bindestriche und keine Sonderzeichen wie ! ? € %.
  • Schlüsselwörter von Python (z. B. False, if, while) sind als Namen verboten.

Konventionen – so macht man es richtig

  • Namen beginnen mit einem Kleinbuchstaben.
  • Namen sollen aussagekräftig sein: summe statt zahl23.
  • Bei langen Namen trennt man die Wörter mit Unterstrich (anzahl_monate) oder mit Großbuchstaben (anzahlMonate).
  • Keine Umlaute und kein ß – das funktioniert zwar, ist aber unüblich: groesse statt größe.
  • Kein _ am Anfang – das ist für Python-interne Daten vorgesehen.

2 Datentypen

Jeder Wert hat einen Datentyp. Er legt fest, was man mit dem Wert machen kann – mit Zahlen kann man rechnen, mit Texten nicht. Mit type(wert) kann man den Datentyp abfragen.

Datentypen umwandeln

Mit int(), float(), str() und bool() kann man einen Wert in einen anderen Datentyp umwandeln. Das braucht man z. B., weil input() immer einen Text liefert. Nicht jede Umwandlung klappt!

Umwandlungs-Labor

print(0.1 + 0.2)          # 0.30000000000000004
print(round(18.705, 2))   # 18.7 – und nicht 18.71

Der Computer speichert Kommazahlen im Binärsystem, also nur mit 0 und 1. Viele Dezimalzahlen wie 0,1 lassen sich dort nicht exakt darstellen – so wie 1/3 = 0,333… im Dezimalsystem nie aufgeht. Gespeichert wird der nächstgelegene Wert: Aus 18.705 wird intern 18.704999999999998…, und das rundet round() korrekt ab.

Für Geldbeträge, bei denen jeder Cent stimmen muss (Banken, Buchhaltung), rechnet man deshalb mit dem Modul decimal oder intern in ganzen Cent.

! Typische Anfängerfehler

Komma statt Punkt

preis = 12,34
preis = 12.34

Mit Komma speichert Python zwei Zahlen (12, 34) statt einer Kommazahl.

Groß-/Kleinschreibung

alter = 16
print(Alter)
alter = 16
print(alter)

Alter gibt es nicht: NameError: name 'Alter' is not defined.

Ungültiger Name

2te-zahl = 5
zweite_zahl = 5

Namen dürfen nicht mit einer Zahl beginnen und keinen Bindestrich enthalten – der wird als Minus gelesen.

Variable ohne Wert benutzt

summe = summe + 5
summe = 0
summe = summe + 5

Eine Variable muss zuerst einen Startwert bekommen, sonst kennt Python sie noch nicht.

In vielen Programmiersprachen hat eine ganze Zahl eine feste Größe, z. B. 32 Bit – der größte Wert ist dann 2 147 483 647.

  • 1996: Die Rakete Ariane 5 explodierte 37 Sekunden nach ihrem ersten Start. Die Steuerungssoftware wandelte eine 64-Bit-Kommazahl in eine 16-Bit-Ganzzahl um – der Wert war zu groß, das Programm stürzte ab. Schaden: mehrere hundert Millionen US-Dollar.
  • 2014: Das Musikvideo „Gangnam Style“ überschritt 2 147 483 647 Aufrufe – mehr, als der Zähler von YouTube speichern konnte. YouTube musste auf 64 Bit umstellen.

In Python kann das bei int nicht passieren: Ganze Zahlen dürfen beliebig groß werden. Probieren Sie print(2 ** 1000).
