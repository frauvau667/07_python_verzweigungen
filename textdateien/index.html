1 Was sind Textdateien?

Bisher lagen alle Daten – Eingaben des Benutzers ebenso wie berechnete Ergebnisse – nur im Arbeitsspeicher. Dieser ist flüchtig: Nach dem Programmende sind die Daten verloren.

Textdateien speichern Daten dauerhaft auf der Festplatte. Sie bestehen aus Zeichen, die in Zeilen angeordnet sind und nacheinander (sequenziell) gelesen werden. Am Ende jeder Zeile steht ein unsichtbares Zeilenumbruch-Zeichen, in Python \n geschrieben.

Die drei Schritte beim Dateizugriff

  1. Öffnen der Datei und Zuweisen zu einer Variablen
  2. Zugreifen: aus der Datei lesen oder in die Datei schreiben
  3. Schließen der Datei

2 Dateien öffnen – mit with

Die Funktion open() öffnet eine Datei. Sie bekommt den Dateinamen und den Modus. Liegt die Datei nicht im selben Ordner wie das Programm, muss der Pfad mit angegeben werden. Am einfachsten ist es, Datei und Python-Programm im selben Ordner zu speichern.

Weil das Schließen leicht vergessen wird, verwendet man die with-Anweisung: Sobald der eingerückte with-Block verlassen wird, schließt Python die Datei automatisch – auch wenn ein Fehler auftritt.

with open("notizen.txt", "w", encoding="utf-8") as datei:
    datei.write("Hallo Welt!")
# hier ist die Datei bereits wieder geschlossen

datei ist der Name, unter dem die geöffnete Datei im with-Block angesprochen wird (oft auch file oder f).

Tipp: encoding="utf-8" angeben. Ohne diese Angabe verwendet Python die Standardkodierung des Betriebssystems. Unter Windows werden Umlaute wie ä, ö, ü dann oft falsch gespeichert oder gelesen. Mit encoding="utf-8" funktioniert es auf allen Systemen gleich.

Eine Datei enthält keine Buchstaben, sondern nur Bytes – also Zahlen. Welche Zahl für welches Zeichen steht, legt die Zeichenkodierung fest. In UTF-8 wird „ä“ als zwei Bytes gespeichert. Liest ein Programm die Datei mit einer anderen Kodierung (z. B. der alten Windows-Kodierung), deutet es jedes Byte einzeln als Zeichen – und aus „ä“ wird „Ã¤“, aus „ü“ wird „Ã¼“.

      
Solchen Zeichensalat nennt man Mojibake (japanisch für „verwandelte Zeichen“). Deshalb steht in allen Beispielen encoding="utf-8": beim Schreiben und beim Lesen dieselbe Kodierung.

    

  


  
  

    
2.1 Aus einer Datei lesen

    
Eine geöffnete Datei kann man mit einer for-Schleife zeilenweise durchlaufen. Jede Zeile ist ein String – einschließlich des Zeilenumbruchs \n am Ende. Weil print() selbst noch einen Zeilenumbruch anhängt, entstehen in der Ausgabe Leerzeilen.

    
Beispiel: Achte im Arbeitsspeicher auf das \n am Ende von zeile und auf die Leerzeilen in der Ausgabe.

    

    
Abhilfe schafft strip(): Es entfernt Leerzeichen, Tabulatoren und Zeilenumbrüche am Anfang und Ende eines Strings.

2.2 In eine Datei schreiben

    
Zum Schreiben wird die Datei im Modus "w" (überschreiben) oder "a" (anhängen) geöffnet. Die Methode write(text) schreibt einen String in die Datei. Dabei gilt:

    
    
      
  • write() akzeptiert nur Strings. Zahlen müssen vorher mit str() umgewandelt werden.
    • 
      
  • write() fügt keinen Zeilenumbruch hinzu. Soll eine neue Zeile beginnen, muss \n angehängt werden.
    • 
    

    

      

        
Text schreiben


with open("notizen.txt", "w", encoding="utf-8") as datei:
    datei.write("Hallo Welt!\n")
    datei.write("Noch eine Zeile.\n")


      

      

        
Zahlen schreiben


with open("zahlen.txt", "w", encoding="utf-8") as datei:
    for i in range(1, 101):
        datei.write(str(i) + "\n")


      

    

    
Die zweite Datei enthält danach die Zahlen 1 bis 100, jede in einer eigenen Zeile. Beim Einlesen erhält man sie wieder als Strings und muss sie mit int() zurückwandeln, um damit zu rechnen.

      


2009 wurde der Spieleanbieter RockYou gehackt. Er hatte die Passwörter von rund 32 Millionen Nutzern im Klartext gespeichert – lesbar wie eine normale Textdatei. Die Liste ist bis heute eines der wichtigsten Werkzeuge beim Passwortknacken. Das häufigste Passwort darin: 123456.

      
Richtig ist es, Passwörter nur als Hashwert zu speichern: eine Art Fingerabdruck, aus dem sich das Passwort nicht zurückrechnen lässt. Beim Anmelden wird das eingegebene Passwort ebenso umgerechnet und nur der Fingerabdruck verglichen. In Python helfen dabei Module wie hashlib.

    

  


  
  

    
3 CSV-Dateien lesen und darstellen

    
CSV-Dateien (comma-separated values) sind Textdateien, die Tabellen speichern: Jede Zeile ist ein Datensatz, die Werte darin sind durch ein Trennzeichen getrennt. In Deutschland ist das meist ein Semikolon ;, im englischsprachigen Raum ein Komma ,. Die erste Zeile enthält in der Regel die Spaltenüberschriften. CSV-Dateien lassen sich auch mit Excel öffnen – jedes Semikolon trennt dort eine Spalte.

    
Vorgehen

    
    
      
  1. Datei zum Lesen öffnen.
    2. 
      
  2. Die erste Zeile mit readline() lesen, mit strip() säubern und mit split(";") in eine Liste der Überschriften zerlegen.
    3. 
      
  3. Die übrigen Zeilen in einer Schleife ebenso mit strip() und split(";") zerlegen und an eine Liste anhängen. Hier kann man die Werte auch gleich auswerten.
    4. 
      
  4. Die entstandene zweidimensionale Liste ausgeben – z. B. als Tabelle mit tabulate.
    5.

Der vollständige Code


import tabulate     # externe Bibliothek, vorher installieren: py -m pip install tabulate

tabelle = []        # leere Liste für die Datensätze

with open("wetter.csv", "r", encoding="utf-8") as datei:
    # erste Zeile: Überschriften
    ueberschrift = datei.readline().strip().split(";")

    # restliche Zeilen: Datensätze
    for zeile in datei:
        werte = zeile.strip().split(";")
        tabelle.append(werte)
        # hier kann jede Zeile ausgewertet werden

print(tabulate.tabulate(tabelle, headers=ueberschrift))


    

      tabulate ist eine externe Bibliothek. Sie wird einmalig im Terminal (z. B. in VS Code) installiert: py -m pip install tabulate unter Windows bzw. python3 -m pip install tabulate. In einem Jupyter-Notebook genügt eine Zelle mit %pip install tabulate.
    


  



  
  

    
3.1 CSV-Dateien lesen mit dem Modul csv

    
Das Zerlegen mit strip() und split(";") funktioniert, hat aber Grenzen: Enthält ein Wert selbst ein Semikolon (z. B. "Müller; Söhne" in Anführungszeichen), wird falsch getrennt. Die Standardbibliothek enthält deshalb das Modul csv, das solche Fälle korrekt behandelt. Eine Installation ist nicht nötig.

    

      

        
WerkzeugLiefert pro ZeileZugriff auf die Temperatur

        
          
split(";")eine Liste von Stringswerte[1]

          
csv.readereine Liste von Strings – Zeilenumbruch schon entferntwerte[1]

          
csv.DictReaderein Dictionary – die Überschriften sind die Schlüsselzeile["Temperatur"]

        
      

    

    

      

        
csv.reader


import csv

with open("wetter.csv", "r", encoding="utf-8", newline="") as datei:
    leser = csv.reader(datei, delimiter=";")
    ueberschrift = next(leser)      # erste Zeile
    for werte in leser:             # jede Zeile ist eine Liste
        print(f"{werte[0]}: {werte[1]} °C")


      

      

        
csv.DictReader


import csv

with open("wetter.csv", "r", encoding="utf-8", newline="") as datei:
    leser = csv.DictReader(datei, delimiter=";")
    for zeile in leser:             # jede Zeile ist ein Dictionary
        print(f"{zeile['Stadt']}: {zeile['Temperatur']} °C")


      

    

    
    
      
  • delimiter=";" gibt das Trennzeichen an. Ohne diese Angabe erwartet das Modul ein Komma.
    • 
      
  • newline="" beim Öffnen überlässt die Zeilenumbrüche dem Modul csv. So wird alles korrekt gelesen – und beim Schreiben entstehen unter Windows keine zusätzlichen Leerzeilen.
    • 
      
  • next(leser) holt die nächste Zeile – hier die Überschriften. Beim DictReader ist das nicht nötig, er liest die Überschriften selbst.
    • 
      
  • Auch hier sind alle Werte Strings. Zum Rechnen: float(zeile["Temperatur"]).
    • 
    

    

      
Was liefert die Schleife? (Inhalt aus dem CSV-Labor)

      

        
        
        
      

      

    

    

      Welche Variante? Für einfache, selbst erzeugte Dateien genügt split(). Für Dateien aus anderen Programmen (z. B. ein Export aus Excel) ist das Modul csv sicherer. DictReader macht den Code besonders gut lesbar, weil man Spalten über ihren Namen statt über einen Index anspricht.
    

  


  
  

    
4 Ganze Dateien schreiben

    
Meist schreibt man nicht nur einzelne Einträge, sondern ganze Listen oder Tabellen in eine Datei – zum Beispiel Messwerte oder die Ergebnisse einer Auswertung. Die Daten liegen dann in einer (zweidimensionalen) Liste und werden in einer Schleife Zeile für Zeile geschrieben.

    
Beispiel: Eine Tabelle wird nur mit open(…, "w") und write() als CSV-Datei gespeichert. Gehe das Programm mit „Schritt“ durch und beobachte, wie die Datei wächst.

    

    
Vier Wege im Vergleich

    

      

        
        
        
        
      

      

      

        

        

      

      

    

    

      

        
MethodeWirkung

        
          
datei.write(text)schreibt einen String – Zeilenumbruch \n selbst anhängen

          
schreiber.writerow(liste)schreibt eine Zeile; Zahlen werden automatisch umgewandelt

          
schreiber.writerows(tabelle)schreibt alle Zeilen einer zweidimensionalen Liste auf einmal

          
dict_schreiber.writeheader()schreibt die Überschriftenzeile (aus fieldnames)

          
dict_schreiber.writerows(liste_von_dicts)schreibt eine Liste von Dictionaries
