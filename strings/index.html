1 Strings – Texte als Zeichenfolgen

Bei der Arbeit mit Benutzereingaben oder Textdateien muss man Texte häufig auswerten: Wie lang ist die Eingabe? Kommt ein bestimmtes Wort vor? Besteht sie nur aus Ziffern? Dafür bietet Python zahlreiche Funktionen und Methoden.

Ein String (str) ist eine Folge von Zeichen – Buchstaben, Ziffern, Leerzeichen, Satzzeichen. Wie bei einer Liste hat jedes Zeichen einen Index, beginnend bei 0.

text = "Hello World"

Oben der Index von vorne, unten (orange) der Index von hinten. Auch das Leerzeichen ist ein Zeichen und hat einen Index.

Strings sind unveränderlich. Methoden wie upper() oder replace() verändern den ursprünglichen String nicht, sondern liefern einen neuen String. Das Ergebnis muss man speichern: text = text.upper(). Ein einzelnes Zeichen kann man nicht ersetzen: text[0] = "h" führt zu einem TypeError. 
print(ord("A"))     # 65
print(chr(65))      # A
print(ord("a"))     # 97
print(ord("€"))     # 8364
print(ord("😀"))    # 128512

Welche Zahl zu welchem Zeichen gehört, legt der Unicode-Standard fest – mit über 150 000 Zeichen aus fast allen Schriften der Welt, inklusive Emojis.

Deshalb kann man Strings vergleichen: "Apfel" < "Birne" ist True, weil 65 < 66. Aber auch "Zebra" < "apfel" ist True, denn alle Großbuchstaben haben kleinere Zahlen als die Kleinbuchstaben.

2 Index und Slicing

Mit text[index] liest man ein einzelnes Zeichen. Mit Slicing text[start:stop:step] schneidet man einen Ausschnitt heraus. Wie bei range() gilt: start ist dabei, stop nicht mehr.

len() ist eine Funktion – der String kommt in die Klammer. Alle anderen sind Methoden – sie werden mit einem Punkt an den String gehängt: text.upper(). Die is…()-Methoden liefern True oder False und eignen sich zum Prüfen von Eingaben:

eingabe = input("Bitte Ihr Alter eingeben: ")
if eingabe.isdigit():
    alter = int(eingabe)
else:
    print("Bitte nur Ziffern eingeben.")

Ein berühmter Informatik-Comic (xkcd) erzählt von einer Mutter, die ihren Sohn Robert'); DROP TABLE Students;-- genannt hat – kurz „Little Bobby Tables“. Als die Schule seinen Namen in ihre Datenbank eintrug, wurde die komplette Schülertabelle gelöscht.

Dahinter steckt die SQL-Injection, eine der häufigsten Sicherheitslücken überhaupt: Ein Programm baut eine Benutzereingabe ungeprüft in einen Datenbankbefehl ein – und die Eingabe enthält selbst Befehle.

Daraus folgt eine Grundregel: Eingaben nie ungeprüft weiterverwenden. Methoden wie isalnum(), isdigit() oder strip() sind ein erster Schritt; Datenbanken bieten dafür zusätzlich sichere „Platzhalter“ an.

5 Einen String zeichenweise durchlaufen

Mit for zeichen in text: nimmt die Schleife nacheinander jedes Zeichen des Strings. So kann man z. B. bestimmte Zeichen zählen.

Beispiel: Ein (etwas ehrlicher) Passwort-Prüfer. Das Programm zählt Ziffern und Großbuchstaben und prüft danach, ob das Passwort mindestens 12 Zeichen lang ist. Gehe das Programm mit „Schritt“ durch und probiere verschiedene Passwörter aus, z. B. Sommer2026, MeinPasswort123 oder KaffeeIstLeer42.

! Typische Fehler

Ergebnis nicht gespeichert

text.upper()
print(text)      # unverändert
text = text.upper()
print(text)

Strings sind unveränderlich – Methoden liefern einen neuen String.

Zeichen direkt ändern

text[0] = "h"
text = "h" + text[1:]

TypeError: 'str' object does not support item assignment

Index zu groß

text = "Hallo"
print(text[5])
print(text[4])   # oder text[-1]

IndexError: string index out of range – bei 5 Zeichen ist 4 der letzte Index. Beim Slicing gibt es dagegen keinen Fehler: text[2:99] liefert einfach 'llo'.

Groß-/Kleinschreibung beim Suchen

"world" in "Hello World"   # False
"world" in "Hello World".lower()   # True

Vergleiche unterscheiden Groß- und Kleinschreibung. Mit lower() auf beiden Seiten wird sie ignoriert.
